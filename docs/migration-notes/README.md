# Archived migration notes

Files in this folder are retained for traceability but are **not deployable Supabase migrations**.

They were moved out of `supabase/migrations/` because they are source-only preparation, duplicate drafts, or superseded by the applied migration history and later Preview fixes. Do not replay these files against any database.

The deployable migration directory is aligned to the Preview migration ledger. Any future schema changes must be added as new timestamped migrations and applied to Preview first.
